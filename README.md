# Shakti Chakra — Immersive Navratri Website

A Shunya-Chakra-inspired immersive single-page experience, redesigned around the supplied Shakti Chakra artwork and branding.

## Files
- index.html
- style.css
- images/

## Publish
Upload all files to GitHub and enable GitHub Pages.

## Customize
- Replace contact phone/email in `index.html`.
- Connect the waitlist form to Formspree, Google Apps Script, your CRM, or a backend before production.
- Add additional official event photographs to `images/` if desired.
