# Shakti Chakra — Animation-Only Website

A Shunya-Chakra-inspired immersive experience rebuilt specifically for Shakti Chakra.

## No image assets
This version intentionally uses **zero image files**. All visual atmosphere is created with:
- CSS mandalas and concentric chakras
- gradients and radial patterns
- rotating rings
- floating particles/fireflies
- pulsing energy
- CSS typography
- JavaScript scroll/counter interactions
